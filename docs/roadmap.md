# Citation Agent — Product Roadmap

> **Citation Agent is building the marketplace where crypto research becomes a measurable, revenue-generating asset for both humans and AI.**

This document is the execution roadmap. Planning stops here. Ship phase by phase; learn from real creators and buyers.

**Public positioning:** The marketplace where crypto research is bought by humans and AI.

**Homepage line:** Turn your crypto research into a revenue-generating asset.

**Internal framing (investors only):** Knowledge commerce infrastructure. Do not use "Shopify of research" in public copy.

---

## Execution principles

These are not roadmap items. They govern every decision.

1. **Protect the niche.** Stay "crypto research marketplace" until traction is undeniable. Do not expand to finance, AI generalism, sports, entertainment, or enterprise sales in public messaging.
2. **One idea everywhere.** Every research report is a **revenue-generating asset** — not a blog post behind a paywall.
3. **Measure what matters.** Do not optimize for creator signups alone. Watch paid unlocks, repeat buyers, creator earnings, and AI purchases.
4. **Ship vertically.** Finish Phase 0 before Phase 1. Finish Phase 1 before Phase 2. No parallel phase jumps.
5. **Ruthless scope.** If a feature does not help someone **publish, discover, buy, or measure** crypto research, it does not ship yet.

## Product scope (crypto only)

### Three publish modes

| Mode | Description |
| --- | --- |
| **Manual publish** | Deep crypto research written natively on Citation |
| **Import & list** | Creator verifies and lists work from Substack, Medium, Mirror, Reddit, or elsewhere |
| **Research desk** | Creator employs a desk that monitors sources and publishes on a novelty-gated schedule |

### Research desk (killer feature)

| Setting | Standard |
| --- | --- |
| Vertical | Crypto only |
| Sources | **Unlimited** — RSS, URLs, newsletters, forums, on-chain mirrors, etc. |
| Cadence | Max posts per week (tier-based); post only when sources show something new |
| Output | UTC timestamp, source lineage, content-type label on every post |
| Owner controls | Display name, price, payout wallet, pause/resume, digest email |
| Revenue | Desk subscription (~$10/mo) + marketplace % on unlocks |

### Research asset (GitHub-for-reports)

Every report gets a permanent asset page:

- Revenue earned
- Unlock count
- Views
- AI purchases vs human purchases
- Citations (referenced by N workflows)
- Reputation impact
- Last updated
- Version history
- Collection membership
- Similar research (knowledge graph)
- Purchase timeline

### Research reputation (compound score)

One overall **Research Reputation** built from:

| Component | Driven by |
| --- | --- |
| Accuracy | Attestations, disputes, refunds |
| Demand | Unlocks, revenue |
| Citations | AI and cross-report references |
| Buyer retention | Repeat unlocks, followers who buy |
| Consistency | Publish cadence, account age |

### Knowledge graph (Phase 3 moat)

Reports link to entities and to each other (e.g. Hyperliquid, Circle, stablecoins). Agents use the graph for discovery and chaining. The marketplace is interconnected, not a flat list.

### Social and demand (retention)

- **Follow creators** — notifications, email updates, feed ranking, repeat buyers
- **Research requests** — buyers post bounties (e.g. "Need a Hyperliquid report — 300 USDC"); researchers compete
- **Public creator profile** — revenue, reports, followers, reputation, citations, collections, top assets
- **Buyer profiles** — purchased research, topics, followed creators (optional privacy)
- **Collections** — Stablecoin Series, Sui Collection, AI x Crypto bundles
- **Leaderboards** — daily / weekly / monthly / all-time by revenue, reputation, unlocks, AI citations

### Marketplace discovery filters

Browse by sector, price, reputation, AI popularity, human popularity, new, trending, most cited, most purchased.

### Creator analytics

Revenue trend, best-selling topic, best publishing time, returning buyers, citation growth, AI/human demand ratio, average unlock price, conversion rate (views to unlock), revenue per collection.

### Authentication

| Phase | Method |
| --- | --- |
| Phase 0 | Email first (magic link or OTP) |
| Phase 0 | Link wallet later (payouts, agent buyers) |
| Phase 4 | Google login |

## Explicitly not on the roadmap

Do not build until post-traction review:

- Enterprise private workspaces (private notes only)
- Sports, entertainment, or multi-vertical expansion
- DAO, governance token, staking
- Tipping, comments, chat, social feed
- NFTs, prediction markets, gamification
- Auto-scrape import without creator verification
- "AI agent platform" or "deploy agents" public messaging

## Phased roadmap

### Phase 0 — Foundation

*Positioning, access, polish*

- [ ] Homepage: revenue-generating asset narrative
- [ ] Language audit: knowledge businesses only
- [ ] Email auth (sign up / sign in)
- [ ] Optional wallet link post-signup
- [ ] Marketplace polish (crypto-only positioning)
- [ ] Basic research asset page shell (revenue, unlocks, views)

**North star:** Email sign-ups leading to first publish.

**Exit:** New visitor understands the product in 10 seconds; creator can sign up with email.

---

### Phase 1 — Marketplace core + retention

*Assets, payments, profiles, follow*

- [ ] Full research asset pages (GitHub-style metrics)
- [ ] Payments / unlock (humans + AI agents)
- [ ] Public creator profiles (research résumé)
- [ ] Creator analytics v1
- [ ] Follow creators + email notifications on new posts
- [ ] Buyer profiles (optional privacy)
- [ ] Import & list (verified ownership)
- [ ] Manual deep crypto publish

**North star:** Active knowledge businesses with unlock revenue.

**Exit:** Creators earn, see analytics, gain followers; buyers follow and unlock.

---

### Phase 2 — Demand + production

*Desk, requests, collections*

- [ ] Research desk ($10/mo, unlimited sources, max posts/week, novelty-gated)
- [ ] Research requests (bounty marketplace)
- [ ] Collections / bundles
- [ ] Desk digest email + pause/resume
- [ ] Collection analytics

**North star:** Paying research desks + fulfilled research requests.

**Exit:** Desks run without daily manual work; bounties drive supply; bundles lift average order value.

---

### Phase 3 — Moat

*Reputation, graph, competition, agent APIs*

- [ ] Research Reputation (five components + overall)
- [ ] Citation tracking ("Referenced by N workflows")
- [ ] Knowledge graph (entity + cross-report links)
- [ ] Leaderboards (four windows x four dimensions)
- [ ] AI APIs (discover, unlock, cite, metadata)
- [ ] Full marketplace filter set
- [ ] Version history on assets

**North star:** Citations per asset + agent API unlocks.

**Exit:** Citations and graph are visible; agents integrate via API; reputation compounds.

---

### Phase 4 — Growth

*Friction removal + upsell*

- [ ] Google login
- [ ] Fiat / card unlocks for human buyers
- [ ] Pro desk plans (posts/week, poll speed, request priority)
- [ ] Apple login (when justified)
- [ ] X source integration (API-priced add-on if needed)

**North star:** Pro plan MRR + fiat unlock share.

**Exit:** Web2 onboarding friction minimal; Pro tier growing.
